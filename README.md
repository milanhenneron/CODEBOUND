# CODEBOUND

Learn to Code. Break the System.

CODEBOUND is a free, open-source, first-person 3D puzzle adventure where programming becomes your most powerful tool.

Status: Concept & pre-production | No playable prototype yet
Planned engine: Godot
First programming language: Houdini VEX
Creator: Milan Henneron, VFX student at ARTFX Montpellier

The Story

You wake up inside a mysterious research facility controlled by AXIOM, an artificial intelligence that observes your every move.

Armed with ARC, a futuristic wrist-mounted programming device, you discover that the facility’s objects and mechanisms can be modified through code.

Your objective is simple: learn the system, outsmart AXIOM, and escape.

Gameplay

CODEBOUND combines exploration, environmental puzzles, storytelling, and real programming.

Players will be able to:

* Explore interconnected futuristic environments.
* Interact with objects through an immersive holographic coding interface.
* Modify object properties and geometry using code.
* Solve puzzles with increasingly advanced programming concepts.
* Discover hidden areas and challenge the facility’s security systems.
* Use acquired programming skills to progress through the story.

Learn Programming by Playing

The first world focuses on Houdini VEX, introducing concepts such as:

* Variables and attributes
* Coordinates and vectors
* Conditional statements
* Loops
* Procedural geometry
* Time-based transformations

For example:

@P.y += 2.0;

A simple instruction could move an object’s geometry upward and help solve an environmental puzzle.

The goal is to make programming feel like an interactive superpower, not a traditional classroom exercise.

Future worlds may introduce Python, C++, JavaScript, and other languages.

Free and Open Source

CODEBOUND is intended to be:

* Completely free to play.
* Open source and community-driven.
* Accessible to students, educators, and curious players.
* Developed without paid gameplay content or subscriptions.

The project’s source code will be published here as development progresses.

An appropriate open-source license will be confirmed as the project takes shape.

Current Development Status

CODEBOUND is currently in the concept and design phase.

There is no playable demo or completed game yet.

The immediate objective is to establish the Godot project architecture, create the core programming interaction system, develop the first environment, and build an initial playable prototype.

The project is seeking development support, particularly access to Claude Code, to accelerate this early production phase.

Development Vision

The long-term ambition is to create a complete narrative adventure where each new programming concept unlocks meaningful gameplay possibilities.

The project will explore AI-assisted development, procedural asset creation, modular level design, and automated testing, while maintaining human creative direction.

Contributing

Community contributions will be welcome once the initial project structure, contribution guidelines, and licensing are established.
